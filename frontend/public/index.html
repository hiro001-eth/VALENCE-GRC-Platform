Honest answers for enterprise buyers

Everything a CISO or GRC lead needs to know before selecting VALENCE.

How is VALENCE different from Vanta or Drata?

While Vanta and Drata check configuration APIs once a day for basic compliance checklists, VALENCE quantifies risk in dollar terms using a 1,000-iteration Monte Carlo FAIR engine, connects natively to SIEM alert feeds (Splunk/Sentinel/Elastic), and seals every piece of evidence with SHA-256 cryptographic hash chains.

Does VALENCE have SOC 2 certification itself?

VALENCE is currently pursuing its SOC 2 Type I certification. We believe in total transparency. Our detailed security architecture, encryption standards, and threat modeling documentation are available on request to prospective enterprise customers.

How long does onboarding take?

SIEM API connection takes between 2 to 4 hours using our read-only endpoints. Your first automated compliance posture report generates within 24 hours, and your first Monte Carlo FAIR risk model can run on day one.

Can VALENCE replace our existing GRC spreadsheets immediately?

Yes. You can import your existing control inventory via CSV or JSON. VALENCE automatically maps your controls across our 10 supported frameworks and replaces static spreadsheets from day one.

What SIEM versions are supported technically?

Splunk Enterprise 8.x+ (via HTTP Event Collector / REST API), Microsoft Sentinel (via Azure Log Analytics / Event Hubs), and Elasticsearch 7.x+ / 8.x+ (using standard ECS schema).

Is there a free trial available?

Yes. The Developer Starter tier is permanently free for individual practitioners. The VALENCE Professional plan includes a 14-day full feature trial with full SIEM and Monte Carlo engine access.

How does multi-tenant isolation work technically?

VALENCE enforces row-level security (RLS) directly at the database layer. Each tenant's data is logically segregated with tenant ID tokens. Tenant admins cannot access cross-tenant data under any condition, backed by cryptographic audit logs.
